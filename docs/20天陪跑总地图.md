## 3. Day13 ~ Day20 升级版路线

### Day13：Docker 化基础环境与一键启动

- 目标：把项目从本机手工拼环境推进成可统一拉起的版本
- 结果：已形成 `docker compose` 本地运行骨架

### Day14：Redis 缓存工程化

- 目标：补齐热点读缓存、失效策略和结果级缓存
- 结果：已拿到代表性量化 `76.5ms -> 15.2ms`

### Day15：Redis 高并发资源竞争

- 目标：围绕限量套餐活动，补齐 Redis Lua 原子校验与一人一单
- 结果：已完成真实页面联调

### Day16：RocketMQ 异步链与延迟关单

- 目标：实现抢购链异步落库、订单超时自动关闭
- 结果：已拿到代表性量化：
  - 异步落库约 `20ms`
  - 延迟关单约 `10s`

### Day17：微服务基础设施进场

- 目标：引入 Nacos、Gateway，建立统一入口与注册发现
- 结果：已形成 `nginx -> gateway -> backend` 最小外层链路

### Day18：最小微服务拆分

- 目标：拆出独立 `product-service`，打通跨服务主链
- 结果：已完成：
  - `gateway -> sky-server -> product-service`
  - `nginx -> gateway -> sky-server -> product-service`

### Day19：traceId 全链路透传

- 目标：让多服务日志可以按单次请求串联
- 结果：已完成：
  - `Gateway Filter + MDC + Feign RequestInterceptor`
  - 命令行 / 浏览器 / 小程序三层验证
  - 主链成功率 `30/30`
  - 日志串联率 `30/30`

### Day20：量化、部署、文档与最终表达收口

- 目标：统一最终数字、部署骨架、文档状态与项目表达
- 当前状态：进行中
