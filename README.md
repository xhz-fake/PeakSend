# PeakSend

峰送商配平台，基于苍穹外卖项目思路进行二次包装与实现的后端实战项目。

## 项目定位

这个项目不仅用于完成课程功能，更用于系统训练以下能力：

- 中后台项目的工程结构理解
- 接口设计、接口调试与前后端联调
- MySQL、Redis、JWT、WebSocket、报表导出等常见后端能力
- 从需求分析到代码落地再到面试表达的完整闭环

## 当前目录说明

- `peaksend-backend/`：后端主工程
- `FrontRunEnv/`：前端运行环境与 Nginx
- `产品原型/`：原型图与页面流转说明
- `项目接口/`：课程提供的静态接口文档
- `docs/`：每日行动指南、变更细节、逻辑链路说明、复盘文档

## 当前路线图

当前项目不是只有一条线，而是分成前后衔接的两段：

- `Day1 ~ Day12`：课程版 `PeakSend`
- `Day13 ~ Day20`：升级版 `PeakSend`

其中：

- 前一段负责把管理端、用户端、下单、支付、订单、提醒、统计、工作台等业务主链做通
- 后一段负责在现有业务骨架上继续补强工程化、缓存、异步消息、微服务和可观测性

当前默认升级路线为：

- `Day13`：Docker 化基础环境与一键启动
- `Day14`：Redis 升级使用与工程化补强
- `Day15`：RocketMQ 基础接入与事件模型设计
- `Day16`：延迟关单与订单时效处理
- `Day17`：通知链异步化与提醒解耦
- `Day18`：Spring Cloud Alibaba 基础设施进场
- `Day19`：核心服务拆分 + 服务调用治理
- `Day20`：日志链路、部署流程与最终表达收口

更详细的总地图和升级版规划，见：

- `docs/12天陪跑总地图.md`
- `docs/PeakSend升级版项目行动规划-Day13起.md`
