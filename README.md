# PeakSend

峰送商配平台，基于苍穹外卖项目思路进行二次包装与实现的后端实战项目。

## 项目定位

这个项目不仅用于完成课程功能，更用于系统训练以下能力：

- 中后台项目的工程结构理解
- 接口设计、接口调试与前后端联调
- MySQL、Redis、JWT、WebSocket、报表导出等常见后端能力
- 从需求分析到代码落地再到面试表达的完整闭环

## 当前目录说明

- `peaksend-backend/`：后端主工程
- `FrontRunEnv/`：前端运行环境与 Nginx
- `产品原型/`：原型图与页面流转说明
- `项目接口/`：课程提供的静态接口文档
- `docs/`：每日行动指南、变更细节、逻辑链路说明、复盘文档

## 文档约定

- 项目总说明统一放在根目录 `README.md`
- 过程性文档统一放在 `docs/`
- 每开始一个新的 Day，在完成当天代码后，必须新增当天的详细说明文档
